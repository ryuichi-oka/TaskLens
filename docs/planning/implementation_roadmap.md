# 実装ロードマップ: TaskLens MVP
日付: 2026-03-25

## 目的
MVP実装の順序と依存関係を明確化し、着実に完成へ導く。

## Phase 0: 基盤準備
- プロジェクト構成確認（SwiftUI / SwiftData / Charts）
- データモデル定義（Task, Category, Tag, TaskTag）
- Seedデータ/サンプルの用意（開発用）

## Phase 1: コアCRUD
- タスク一覧表示（カードUI）
- タスク作成/編集モーダル
- タスク削除
- 状態/カテゴリ/タグのフィルタ
- ローカル保存の永続化確認

## Phase 2: スケジュール
- 日付切替UI（前/今日/次）
- 0:00-24:00の時間軸レイアウト
- 予定枠表示（タイトル/時間帯/カテゴリ色）
- ドラッグ&ドロップ（15分スナップ）

## Phase 3: 分析
- 予実差分（棒グラフ）
- カテゴリ別時間（横棒 or 円）
- 週次サマリ（折れ線）
- 集計ロジックのテスト

## Phase 4: 設定
- カテゴリ管理（追加/編集/削除、色・並び順）
- タグ管理（追加/編集/削除）

## Phase 5: 仕上げ
- 主要フローの動作確認
- パフォーマンス/表示崩れの微調整
- MVP受け入れ基準のチェック

## 依存関係メモ
- 分析は Task/Category/Tag の保存が前提
- スケジュールは Task の plannedStartAt/EndAt が前提
- フィルタは Category/Tag が前提
