# エラー文言・バリデーション文言の統一表
日付: 2026-03-25

## 方針
- 短く具体的に
- ユーザーの次の行動が分かる文面
- 同じ条件は同じ文言に統一

## タスク入力（共通）
- タイトル未入力: 「タイトルは必須です」
- タイトル文字数超過: 「タイトルは50文字以内にしてください」
- メモ文字数超過: 「メモは500文字以内にしてください」
- 予定時間が負: 「予定時間は0以上で入力してください」
- 実績時間が負: 「実績時間は0以上で入力してください」
- 予定/実績が極端に大きい: 「時間が大きすぎます（上限: 9999分）」
- 終了 < 開始: 「終了時間は開始時間より後にしてください」

## カテゴリ管理
- 名称未入力: 「カテゴリ名は必須です」
- 名称重複: 「同じ名前のカテゴリがあります」

## タグ管理
- 名称未入力: 「タグ名は必須です」
- 名称重複: 「同じ名前のタグがあります」

## 共通操作
- 保存失敗: 「保存に失敗しました。もう一度お試しください」
- 削除失敗: 「削除に失敗しました。もう一度お試しください」
- 読み込み失敗: 「読み込みに失敗しました。再度お試しください」

## トースト（成功）
- 保存成功: 「保存しました」
- 作成成功: 「作成しました」
- 削除成功: 「削除しました」
