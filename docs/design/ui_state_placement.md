# UI状態仕様（Loading/Empty/Error/Success）配置
日付: 2026-03-25

## 共通ルール
- 画面中央に主メッセージ、下に補助文
- アクションが必要な場合は主メッセージ下に配置
- 既存コンテンツがある場合はインライン表示を優先

## Loading
- 全画面：中央スピナー + 「読み込み中」
- インライン：リスト最下部に小スピナー

## Empty
- 全画面：中央にアイコン + タイトル + サブ文
- CTA：必要に応じてボタン or FAB利用

## Error
- 全画面：中央にエラー文 + 再試行ボタン
- インライン：リスト内にエラーメッセージ行
- トースト：操作失敗（保存/削除）に使用

## Success
- トーストで短時間表示（画面中央下部）

## 画面別の配置
### タスク一覧
- Empty: 画面中央
- Error: 全画面 + 再試行
- Loading: 全画面

### スケジュール
- Empty: 画面中央
- Error: 全画面 + 再試行
- Loading: 全画面

### 分析
- Empty: 画面中央
- Error: 全画面 + 再試行
- Loading: 全画面

### カテゴリ/タグ管理
- Empty: 画面中央
- Error: 全画面 + 再試行
- Loading: 全画面
