# UI/UX設計: TaskLens デザイン仕様 最終統合
日付: 2026-03-25

## 目的
見える化して管理しやすい体験を提供するため、全画面のデザインルールと詳細仕様を統合する。

## デザイン原則
- 情報の優先度が一目で分かる（期限/優先度/状態を強調）
- 余白とグリッドで可読性を高める
- 色は意味にのみ使う（装飾は抑える）
- 一貫したコンポーネントと状態表現

- ボーダー: #E5E7EB

- 見出し: 17pt / Semibold

- 画面左右余白: 16pt
- セクション間隔: 16pt
- カード内余白: 12pt
- 行間: 4-6pt
- 角丸: 12pt（カード/モーダル）
- 角丸: 24pt（フローティングボタン）

## 共通コンポーネント

- 3タブ（一覧/スケジュール/分析）

### ヘッダー
- 左: ハンバーガー
- 中央: タイトル
- 右: 予備

### フローティングボタン
- 右下固定、直径56pt
- 背景: #2563EB

### フィルタチップ
- 高さ: 28pt
- 選択: 背景 #E0E7FF / 文字 #1D4ED8 / 枠線 #C7D2FE
- 未選択: 背景 #F3F4F6 / 文字 #374151

### 状態バッジ
- Todo: 背景 #E5E7EB / 文字 #374151

- Done: 背景 #DCFCE7 / 文字 #166534
- 角丸: 10pt / パディング 4x8

## 画面別仕様
### タスク一覧
- ヘッダー: 「一覧」
- フィルタチップ行: 状態/カテゴリ/タグ
- タスクカード（3行）
- 1行目: タイトル / 状態バッジ
- 2行目: 期限 / 優先度（期限超過は赤 + 警告）
- 3行目: 予定/実績（数値強調） / カテゴリ色ドット
- 空状態: 「タスクがありません」

### スケジュール
- ヘッダー: 「スケジュール」
- 日付切替: 前/次 + 日付表示
- 「今日」ボタン: 画面上部左側（ハンバーガー右隣）
- 時間軸: 0:00-24:00（15分補助線）
- 予定枠: カテゴリ色薄背景 + 左アクセント線
- 重複表示: 横幅分割、優先度高が左
- 空状態: 「予定がありません」

### 分析
- セクション1: 予実差分（棒グラフ）
- X軸: MVPは日付（将来切替でカテゴリ）
- セクション2: カテゴリ別時間（横棒推奨）
- セクション3: 週次サマリ（折れ線）
- 空状態: 「データがありません」

### タスク詳細/新規作成モーダル
- 画面下シート、角丸16pt
- フィールド: タイトル/メモ/状態/予定/実績/開始/終了/期限/優先度/カテゴリ/タグ
- 保存: 必須未入力は無効
- 削除: 詳細のみ下部に赤ボタン

### カテゴリ/タグ管理
- ヘッダー: 戻る / タイトル / 追加
- カテゴリ: 色ドット + 並び順ハンドル
- タグ: 色ドット + シンプル行
- 空状態: 「カテゴリがありません」「タグがありません」

## 状態・エラー・空状態ルール
- 読み込み中: スピナー + 「読み込み中」
- 保存中: 保存ボタン無効 + インジケータ
- バリデーション: 赤枠 + エラー文
- トースト: 画面中央下部、2-3秒、標準スタイル
- 破壊的操作: 確認ダイアログ

## アニメーション
- 状態遷移: 150ms フェード
- カード追加: 200ms フェード+スライド
- ドラッグ: 120ms スケール、ドロップ150ms
- グラフ描画: 300ms フェード

## アクセシビリティ
- コントラスト比 4.5:1 以上
- タップ領域 44pt 以上
