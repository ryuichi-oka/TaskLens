# UI/UX設計: タスク一覧 画面ビジュアル詳細
日付: 2026-03-25

## 目的
重要情報（期限/優先度/状態）を最短で把握できる視認性を確保する。

## 画面構成
- ヘッダー
- フィルタチップ行
- タスクカードリスト
- フローティングボタン

## ヘッダー
- 高さ: 56pt
- 左: ハンバーガー（SF Symbols: line.3.horizontal）
- 中央: 画面タイトル「一覧」
- 右: 予備（空 or 編集）
- 背景: #FFFFFF（分離線 #E5E7EB）

## フィルタチップ行
- 水平スクロール
- チップ高さ: 28pt
- 余白: 左右16pt、上下8pt
- チップ間隔: 8pt
- 状態: `状態` / `カテゴリ` / `タグ`
- 選択時: 背景 #E0E7FF / 文字 #1D4ED8 / 枠線 #C7D2FE
- 未選択: 背景 #F3F4F6 / 文字 #374151 / 枠線なし

## タスクカード
- 背景: #F7F7F8
- 角丸: 12pt
- 余白: 外側16pt、カード内12pt
- 高さ: 可変（内容による）
- 行構成: 3行

### 1行目
- 左: タイトル（15pt Semibold, #111827, 1-2行）
- 右: 状態バッジ

### 2行目
- 左: 期限（12pt, Secondary #4B5563）
- 右: 優先度（12pt, Secondary #4B5563）
- 期限超過時: テキスト #DC2626 + 小さな警告アイコン（exclamationmark.triangle）

### 3行目
- 左: 予定/実績（15pt Semibold, #111827）
- 右: カテゴリ色ドット（直径8pt）

## 状態バッジ
- Todo: 背景 #E5E7EB / 文字 #374151
- Doing: 背景 #DBEAFE / 文字 #1D4ED8
- Done: 背景 #DCFCE7 / 文字 #166534
- 角丸: 10pt
- パディング: 4pt x 8pt
- フォント: 12pt Semibold

## フローティングボタン
- 右下: 24ptマージン
- 直径: 56pt
- 背景: #2563EB
- アイコン: plus（白）

## 空状態
- タイトル: 「タスクがありません」
- サブ: 「右下の + から作成しましょう」
- アイコン: checklist
- 配置: 画面中央

## 重要情報の強調ルール
- 期限/優先度は必須表示
- 期限超過は赤強調
- 状態は色とバッジで判別
- 予定/実績は数値強調で並列表示

## アニメーション
- カード追加: 200ms フェード+スライド
- フィルタ切替: 150ms フェード
