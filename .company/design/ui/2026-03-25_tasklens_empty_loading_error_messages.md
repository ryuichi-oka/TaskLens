# 空状態・読み込み・エラー文言セット
日付: 2026-03-25

## 空状態
- タスク一覧: 「タスクがありません」 / 「右下の + から作成しましょう」
- スケジュール: 「予定がありません」 / 「+ から予定を追加」
- 分析: 「データがありません」 / 「タスクに予定/実績を入力すると表示されます」
- カテゴリ管理: 「カテゴリがありません」 / 「+ から追加」
- タグ管理: 「タグがありません」 / 「+ から追加」

## 読み込み中
- 「読み込み中」

## エラー
- 共通（読み込み失敗）: 「読み込みに失敗しました。再度お試しください」
- 共通（保存失敗）: 「保存に失敗しました。もう一度お試しください」
- 共通（削除失敗）: 「削除に失敗しました。もう一度お試しください」
