# UI/UX設計: TaskLens ワイヤー
日付: 2026-03-22

## 目的
視認性重視のシンプルな画面構成で、タスク入力〜分析までの導線を明確にする。

## 画面一覧
- タスク一覧（Tab）
- タイムスケジュール（Tab）
- 分析（Tab）
- タスク詳細モーダル（共通）
- 新規作成モーダル（共通）
- 設定（ハンバーガーメニュー）
- カテゴリ管理
- タグ管理

## 共通ナビゲーション
- 画面下部にタブバー
- 右下にフローティングボタン（+）
- ヘッダー左にハンバーガーメニュー

## タスク一覧（Tab）
- ヘッダー: タイトル / ハンバーガー
- フィルタ: 状態 / カテゴリ / タグ
- リスト: タスクカード
  - タイトル
  - 状態バッジ
  - 期限（必須表示）
  - 優先度（必須表示）
  - 予定/実績（分）
  - カテゴリ色
- 操作: タップで詳細モーダル
- フローティングボタン: 新規作成

## タイムスケジュール（Tab）
- ヘッダー: 日付切替（前/今日/次）
- 時間軸: 0:00-24:00 の縦リスト
- 予定枠: タスクブロック
  - タイトル
  - 予定時間帯
  - カテゴリ色
- 操作
  - タップで詳細モーダル
  - ドラッグ&ドロップで時間変更（15分スナップ）
  - 重複は許可
- フローティングボタン: 新規作成

## 分析（Tab）
- セクション1: 予実差分
  - 棒グラフ（予定/実績の2本）
  - 差分ラベル
- セクション2: カテゴリ別時間
  - 横棒 or 円グラフ
- セクション3: 週次サマリ
  - 折れ線（1週間の日別合計）

## タスク詳細モーダル
- フィールド: タイトル / メモ / 状態
- 時間: 予定時間 / 実績時間
- スケジュール: 開始 / 終了
- 期限 / 優先度
- カテゴリ / タグ
- 操作: 保存 / 削除

## 新規作成モーダル
- タスク詳細モーダルと同じ項目
- 操作: 作成

## 設定
- メニュー
  - カテゴリ管理
  - タグ管理
  - 重複挙動設定（将来）

## カテゴリ管理
- リスト表示
- 追加 / 編集 / 削除

## タグ管理
- リスト表示
- 追加 / 編集 / 削除

## ユーザーフロー（主要導線）
- タスク作成: タブ内の + → 新規作成モーダル → 保存
- タスク編集: リスト/スケジュールのタップ → 詳細モーダル → 保存
- 分析閲覧: タブ切替 → グラフ確認
