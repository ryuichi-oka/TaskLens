# 入力ルールの上限/制約整理
日付: 2026-03-25

## タスク
- タイトル: 必須 / 最大50文字
- メモ: 任意 / 最大500文字
- 状態: Todo/Doing/Done
- 予定時間: 0〜9999分
- 実績時間: 0〜9999分
- 開始/終了: 15分刻み
- 終了は開始以降（同時刻可）
- 期限: 任意
- 優先度: 1〜3
- カテゴリ: 任意（1つ）
- タグ: 任意（複数）

## カテゴリ
- 名称: 必須 / 最大20文字
- 色: プリセットから選択
- 並び順: 整数（1〜999）

## タグ
- 名称: 必須 / 最大20文字
- 色: プリセットから選択

## 共通
- 空文字は不可（必須項目）
- 末尾/先頭の空白はトリム
- 同名は不可（カテゴリ/タグ）
