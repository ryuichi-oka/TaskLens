# 機能仕様: TaskLens 要件/必須機能（MVP）
日付: 2026-03-25

## 概要
タスクのCRUD、予定/実績管理、タイムスケジュール表示、分析可視化をローカル保存で提供するMVP要件を整理する。

## 前提・制約
- 初期はローカル保存（SwiftData）
- 予定/実績は手入力が基本（自動計測は将来）
- スケジュールは単一の予定枠（plannedStartAt/EndAt）
- 15分スナップで時間調整
- 重複はMVPで許可

## 画面構成（MVP）
- タスク一覧（Tab）
- タイムスケジュール（Tab）
- 分析（Tab）
- タスク詳細モーダル（共通）
- 新規作成モーダル（共通）
- 設定
- カテゴリ管理
- タグ管理

## 主要機能（MVP）
| 優先度 | 機能名 | 概要 |
|--------|--------|------|
| 高 | タスクCRUD | タスクの作成/閲覧/編集/削除 |
| 高 | 予定/実績入力 | 予定時間・実績時間の手入力と保存 |
| 高 | タスク一覧表示 | 状態/カテゴリ/タグのフィルタ、カード表示 |
| 高 | スケジュール表示 | 0:00-24:00の時間軸に予定枠を表示 |
| 高 | ドラッグ&ドロップ | 予定枠を15分単位で移動（重複可） |
| 中 | 分析: 予実差分 | 予定/実績の棒グラフ + 差分ラベル |
| 中 | 分析: カテゴリ別時間 | 横棒 or 円グラフでカテゴリ別集計 |
| 中 | 分析: 週次サマリ | 1週間の日別合計の折れ線 |
| 中 | カテゴリ管理 | 追加/編集/削除（色・並び順） |
| 中 | タグ管理 | 追加/編集/削除 |

## 画面別要件（要点）
### タスク一覧
- 必須表示: 期限、優先度
- タスクカード: タイトル/状態/期限/優先度/予定実績/カテゴリ色
- タップで詳細モーダル

### タイムスケジュール
- 日付切替（前/今日/次）
- 予定枠表示: タイトル/時間帯/カテゴリ色
- タップで詳細、ドラッグで時間変更（15分スナップ）

### 分析
- 予実差分（棒グラフ）
- カテゴリ別時間（横棒 or 円）
- 週次サマリ（折れ線）

### タスク詳細モーダル / 新規作成
- フィールド: タイトル/メモ/状態/予定/実績/開始/終了/期限/優先度/カテゴリ/タグ
- 操作: 保存/削除（新規は作成）

## データ要件（主要項目）
- Task: title, notes, status, category, tags, plannedMinutes, actualMinutes, plannedStartAt, plannedEndAt, dueAt, priority, createdAt, updatedAt
- Category: name, colorHex, sortOrder
- Tag: name, colorHex
- 関係: Task 1 - 0..1 Category, Task N - N Tag

## 将来拡張（参考）

- 実績計測の詳細化（開始/終了ログ）
- 複数予定枠
