# 技術仕様: GitHub テンプレート
日付: 2026-03-25

## 概要
GitHub リポジトリ運用のため、Issue テンプレートと PR テンプレートを追加する。

## 技術選定
- 言語/フレームワーク: GitHub Issue Forms (`.yml`) / Markdown (`.md`)
- 理由:
  - GitHub 標準機能で追加依存が不要
  - 入力必須項目を定義しやすく、報告内容を揃えられる

## 設計
- `bug_report.yml`
  - 再現手順、期待値、実際の結果、環境、影響範囲を収集
- `feature_request.yml`
  - 解決したい課題、提案内容、ユースケース、完了条件を収集
- `config.yml`
  - 空白 Issue を抑止し、Discussion を案内
- `pull_request_template.md`
  - 変更概要、背景、確認方法、スクリーンショット、チェックリストを定義
  - 見出しと案内文は日本語で統一する

## 実装メモ
- 現在のリポジトリ構成が Swift / Xcode ベースのため、テンプレート文言もそれに馴染む形に調整する
- 既存 `.github/` ディレクトリがなかったため新規作成とする
- 運用ルールとして、Issue と PR は日本語で作成する前提にそろえる

## 動作確認方法
- GitHub 上で新規 Issue 作成時にテンプレート一覧が表示されること
- PR 作成時にテンプレート内容が自動挿入されること
