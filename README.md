# AI エージェントチーム — OpenAI Codex 版

個人開発者がソロで複数の「仮想部門」を持ち、OpenAI Codex を使って効率よく作業を進めるためのフレームワーク。

## 特徴

- **秘書が受付**: すべての依頼を秘書が受け取り、適切な部門に振り分ける
- **役割分担が明確**: リサーチ・開発・企画 が独立して動く
- **ファイルで記録**: タスク・議事録・成果物をすべて `.company/` 配下に保存
- **Claude Code 版も存在**: 元は Claude Code 向けに設計（AGENTS.md → CLAUDE.md に読み替えで使用可能）

## セットアップ

```bash
git clone https://github.com/tanishi-10/CodeX_Company.git
cd CodeX_Company
```

あとは Codex を起動してプロジェクトを開くだけ。`AGENTS.md` が自動的に読み込まれる。

## 使い方

普通に話しかけるだけでOK：

```
「新しいアプリのアイデアを整理したい」
「今日やることを確認して」
「〇〇について競合調査してほしい」
「ログイン機能を実装したい」
```

秘書がすべて受け付けて、必要な部門に振り分ける。

## 組織構成

```
社長（あなた）
    ↓
秘書（Secretary） ← すべての依頼の窓口
    ↓
CEO → リサーチ / 開発 / 企画
```

詳細は [AGENTS.md](./AGENTS.md) を参照。

## ディレクトリ構成

```
.
├── AGENTS.md               # Codex 向けメイン設定
├── README.md
└── .company/               # 部門ごとの作業ディレクトリ
    ├── secretary/          # タスク・ログ・受付
    ├── ceo/                # 意思決定ログ
    ├── research/           # 市場調査・競合分析
    ├── engineering/        # 技術仕様・開発メモ
    ├── design/             # DB設計・API設計・UI設計
    ├── infra/              # 環境構成・デプロイ手順・CI/CD設定
    ├── qa/                 # テスト計画・バグレポート・レビュー結果
    └── planning/           # 企画書・ロードマップ
```

## Claude Code 版との違い

| 項目 | Claude Code 版 | Codex 版（本リポジトリ） |
|------|--------------|----------------------|
| 設定ファイル | `CLAUDE.md` | `AGENTS.md` |
| 部門呼び出し | スキル（`/secretary` 等） | 自然言語で話しかける |
| ファイル構造 | 同じ | 同じ |
